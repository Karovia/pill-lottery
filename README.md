# 像素大转盘 · Pill Lottery

一个像素风的**通用抽奖模板**：小恐龙站在转盘正中央，点它一下（或按空格）跳过仙人掌，
转盘随即开转抽出奖品，并播放对应结算片段（可选）。昼夜主题可手切可自动循环，
转盘的选项、每个选项的奖品数、名称全部在控制面板里调。

> 影视/动画片段（版权素材）**不在仓库中**，放入自己的片段即可启用结算视频；
> 没有片段时页面自动降级为像素台词卡片，功能完整。

## 玩法

1. **点恐龙 / 按空格** → 恐龙跳过仙人掌 → 转盘旋转 → 停在某个选项上
2. **昼夜主题**：点页面顶部的徽章随时切换白天/夜晚（整页同步渐变）；
   也可在控制面板开启"自动循环"（每 15~25 秒自动翻转）
3. **抽中的扇形被填满标记**：每个选项按奖品数均分格子，抽走一格填一格，
   全部抽完整个扇形反色
4. **隐藏大奖彩蛋**（可选）：最后一个选项的最后一格被抽中时，
   胜利音效 + 全屏像素彩带 + 礼品弹窗
5. **全部抽完 → 锁定等待补货**；管理员**长按红色 RESET 按钮 2 秒**
   （像素方块进度环）→ 仙人掌撞倒恐龙 → GAME OVER → 自动清空重开

进度保存在浏览器 localStorage，刷新不丢。

## 控制面板

点右上角「设置」打开：

| 设置项 | 说明 |
|---|---|
| 昼夜自动循环 | 开关自动翻转白天/夜晚 |
| 奖位选择方式 | 按昼夜（白天抽第 1 格 / 夜晚抽最后 1 格）或剩余随机 |
| 奖位名称 | 每个选项内各奖位的名字，逗号分隔（如"上午，下午"） |
| 隐藏大奖彩蛋 | 最后一个选项最后一格触发彩带+礼品弹窗 |
| 转盘选项 | 选项名称 + 每个选项的奖品数量（2~12 个选项，各 1~6 个奖品），可增删 |

改小选项/奖品数会丢弃对应进度；「恢复默认」回到"周一~周日 × 上午/下午"的原始配置。

## 运行

```bash
python3 server.py 8642
# 打开 http://127.0.0.1:8642
```

或直接双击 `index.html`。

### 打包成 macOS App（可选）

需要 Xcode Command Line Tools（`swiftc`）与 `ffmpeg`、`iconutil`：

```bash
bash macos-app/build.sh
# 生成 吃药大转盘.app —— WKWebView 壳，资源全部打进包内，双击即开
```

## 自定义结算片段

放入 `assets/clips/`，按"选项下标_奖品下标"命名（都从 0 开始）：
`0_0.mp4`、`6_1.mp4`…；也可以在 `js/clips.js` 里按 `"选项:奖品"` 配置路径与台词。
详见 `assets/clips/README.md`。**请勿把版权片段上传到公开仓库。**

## 结构

```
├── index.html          页面 + 控制面板
├── css/style.css       像素风样式（昼/夜调色板由 JS 统一驱动）
├── js/app.js           全部逻辑：跑酷/转盘/状态机/面板/音效/存档
├── js/clips.js         可选：片段路径与台词的定制配置
├── server.py           本地静态服务器（no-store 缓存头）
├── macos-app/          macOS 原生壳（WKWebView + 自定义 URL Scheme）
└── assets/
    ├── clips/          结算视频（自行补充，不入库）
    ├── sprites/        Chrome 恐龙官方精灵图及切片
    └── fonts/          缝合像素字体 Fusion Pixel（OFL 1.1）
```

## 技术备忘

- 恐龙动画四帧循环（左脚前 → 收拢 → 右脚前 → 收拢）取自官方精灵图逐像素分析切片
- 全部渲染在一张 560×560 逻辑画布：外圈转盘环 + 中央小舞台（恐龙/传送带地面/仙人掌）
- 昼夜反转：一份调色板由 JS 每帧同时驱动画布与页面 CSS 变量，整页同步渐变
- 音效为 WebAudio 实时合成的 8-bit 音，无音频文件
- 调试钩子：控制台 `__pill.toggleTheme()` / `__pill.reset()` / `__pill.testSpecial()`
