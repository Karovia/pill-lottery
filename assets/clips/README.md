# assets/clips/ — 结算片段（自行补充）

版权原因，仓库**不包含**任何影视/动画片段。放入片段后页面自动播放；
缺失时自动降级为像素台词卡片，页面功能不受影响。

## 命名

按"选项下标_奖品下标"命名（都从 0 开始），与控制面板里的选项顺序对应：

```
0_0.mp4  0_1.mp4     ← 第 1 个选项的 2 个奖品
1_0.mp4  1_1.mp4     ← 第 2 个选项 …
…
6_0.mp4  6_1.mp4     ← 第 7 个选项
```

也可以不改文件名，直接在 `js/clips.js` 里按 `"选项:奖品"` 指定路径和台词。

## 规格建议

- 时长 4~8 秒，包含关键台词/动作的完整时刻
- 640 宽、H.264 + AAC、faststart：

```bash
ffmpeg -y -ss <起点秒> -i 源视频.mp4 -t 7 \
  -vf "scale=640:-2,fps=30" -c:v libx264 -preset veryfast -crf 23 \
  -pix_fmt yuv420p -profile:v baseline -c:a aac -b:a 128k -movflags +faststart out.mp4
```

## 合规提醒

影视剧切片属版权素材，请自行确认使用场景合规，不要上传到公开仓库。
